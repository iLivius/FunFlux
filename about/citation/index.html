    Citation and references¶

    Use this page when you publish results from FunFlux. It gives the reference for FunFlux itself and for the v1 workflows. It then lists, stage by stage, the tools and databases a run can use, with their versions and the numbers of their references. The page ends with the acknowledgements, the full list of references and the works cited on Validation on public genomes.

    Terms used on this page
    concept DOI the Zenodo DOI shared by all versions of a record, which always leads to the newest; each version also has a DOI of its own
    contig filter rule filter_contigs: on SPAdes-style headers it drops contigs under 500 bp or 2x coverage; other headers are only cut at their first space or tab
    mitochondrion screen rule screen_mitochondria, part of the contamination and mitochondrion screen: it confirms mitochondrial contigs from BLAST hits to mitochondrial genomes and, in the long-read modes, the assembler's evidence
    contig selector rule select_contigs, the last step of the screen: it keeps or removes each contig by genus, as parameters.decontamination says; the default, off, keeps every contig
    ITS window the stretch cut around one 5.8S gene, 2,000 bp on each side by default, turned to read from SSU to LSU before ITSx runs
    contig summary the table 02.assembly/{sample}/eval/contig_summary.tsv: one row per contig of the draft, with its evidence (telomeres, depth, rDNA units, genes) and a verdict
    AMR screen the optional resistance-mutation screen, off by default (parameters.amr.chroquetas), in which ChroQueTas looks in each genome for the changes FungAMR lists for the species
    funannotate database the frozen snapshot of funannotate's data, such as Swiss-Prot, Pfam, the BUSCO set and stored AUGUSTUS models, downloaded once from Zenodo into directories.funannotate_db

    Citing FunFlux¶

    Antonielli, L., & Brader, G. (2026). FunFlux: Integrated workflow for fungal genome assembly and annotation (v2.1.0). Zenodo. https://doi.org/10.5281/zenodo.13612159

    The DOI 10.5281/zenodo.13612159 is the concept DOI, which always resolves to the newest version. Each release also has a version DOI of its own on Zenodo. Cite the version DOI when the exact code matters.

    The repository is https://github.com/iLivius/FunFlux, and the documentation is at https://iLivius.github.io/FunFlux/. FunFlux is released under the MIT License. See Licensing.

    The contig filter, the mitochondrion screen, the contig selector and the ITS windows have no tool of their own to cite, so cite FunFlux for them. The contig filter of contigs mode, the contig selector and the layout of the workflow come from BacFlux, which is also released under the MIT License.

    For the contig summary, tidk does the telomere search, so cite tidk with FunFlux. The papers behind FunFlux's table of telomere repeat units are listed in the Contig summary rows under Tools and databases.

    The ChroQueTas authors ask to be cited through the FungAMR paper

    The AMR screen runs ChroQueTas. As the ChroQueTas authors ask, cite FungAMR and ChroQueTas through the FungAMR paper (Bédard et al. 2025). Cite the tools ChroQueTas runs as well, which are listed in the AMR screen rows under Tools and databases.
