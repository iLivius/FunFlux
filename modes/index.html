    Modes¶

    The configuration key mode selects the front end, the steps that turn the input into an assembly. The launch command does not change with the mode. This page sets the four modes side by side and compares their steps, the contamination and mitochondrion screen as each mode runs it, and the files each mode writes. Read it when you choose a mode, or to look up what a mode does.

    From the screen on, every mode runs the same steps, and only polishing differs between the read-based modes. Every mode produces 02.assembly/{sample}/contigs_final.fasta. This file is the nuclear genome alone when the screen runs with the default parameters.mitochondria.mode: separate_confirmed. Otherwise nothing is split off, and any mitochondrial contig stays in it.

    From that file on, all four modes run QUAST, BUSCO, ITS extraction and classification, repeat masking, gene prediction, functional annotation and the MultiQC report. Two of these steps take extra inputs in some modes. In hybrid mode QUAST also reports the Illumina guide assembly, and MultiQC adds the read-QC and mapping tables of the modes that have reads.

    Terms used on this page
    front end the steps that differ by mode, chosen by mode: read processing, assembly and contig filter before the shared screen, and polishing after it
    the screen the contamination and mitochondrion screen of the draft: BLAST against core_nt, BlobTools, the mitochondrion screen and the contig selector; in contigs mode only with parameters.contigs.screen: true
    draft assembly (the draft) the assembly the screen examines, before any contig is removed
    contig selector rule select_contigs, the last step of the screen: it keeps or removes each contig by genus, as parameters.decontamination says; the default, off, keeps every contig
    genus filter the setting parameters.decontamination.mode: include or exclude, under which the contig selector keeps or removes contigs by the genus BlobTools gave them
    guide assembly in hybrid mode, the SPAdes assembly of the Illumina reads; it is screened, and only the pairs that map to it go on
    assembler evidence what hifiasm or Flye report for each contig, above all read depth and circularity, written to assembly_evidence.tsv for the mitochondrion screen; longread and hybrid only

    contigs mode skips every read and assembly step and runs the screen only with parameters.contigs.screen: true. hybrid mode combines the other two read-based modes. Its Illumina steps build a guide assembly and select reads, its long-read steps build the genome that is delivered, and Polypolish corrects that genome with the Illumina pairs.

    In longread and hybrid mode the read technology is taken from each file name, so one batch can hold ONT and PacBio HiFi samples. The flags that differ between the two technologies are listed on Long reads.

    The contamination and mitochondrion screen¶

    The screen checks every contig of the draft assembly. BLAST compares each contig with NCBI core_nt, and BlobTools gives it a genus. The mitochondrion screen looks for the mitochondrial genome among the contigs, and the contig selector keeps or removes each contig and records the decision. With the default parameters.mitochondria.mode: separate_confirmed, the contig selector keeps a confirmed mitochondrial contig whatever the genus filter says. Polishing comes after the screen, on the contigs that were kept.

    The screen is the same in every mode. Three things change with the mode: the draft it examines, the reads behind the BlobTools coverage and the evidence for the mitochondrion.

    illumina longread hybrid contigs with the screen
    Draft screened contigs_filt.fasta assembly.fasta the guide's contigs_filt.fasta, then assembly.fasta contigs_filt.fasta
    Reads behind the BlobTools coverage trimmed Illumina pairs, bowtie2 filtered long reads, minimap2 guide: Illumina pairs, bowtie2; long-read assembly: filtered long reads, minimap2 none; the contigs are mapped to themselves and the coverage carries no information
    Evidence for the mitochondrion BLAST BLAST plus the assembler's read depth and circularity guide: BLAST; long-read assembly: BLAST plus assembler evidence BLAST

    A long-read assembler adds read depth and circularity to BLAST when the mitochondrion is judged. hybrid mode runs the screen twice, on the guide as in illumina and on the long-read assembly as in longread. In contigs mode there are no reads, so the BlobTools coverage carries no information and BLAST alone decides.

    With the default settings, the screen removes no contig

    The screen is on in every read-based mode and off in contigs mode unless parameters.contigs.screen: true. With the default parameters.decontamination.mode: off, it removes no contig but records a decision for each one and splits off the confirmed mitochondrion. See Decontamination and Mitochondria.
